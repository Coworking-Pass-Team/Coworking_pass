# Documentation

Documentation for Coworking Pass Version 2.0. Every file here has an Arabic copy with the same name in `docs/ar/`
(kept on the team's machines, not in the public repository).

## Product and requirements
* [PRD.md](PRD.md): vision, personas, business model and product rules.
* [SRS.md](SRS.md): roles, user stories and functional requirements with IDs, acceptance criteria and status.

## Design
* [System_Architecture.md](System_Architecture.md): stack, request flows, i18n, security and deployment.
* [ERD.md](ERD.md): entity-relationship diagram, tables and data integrity rules.
* [Notifications_and_Emails.md](Notifications_and_Emails.md): every in-app notification and email, with its trigger,
  recipient and status.

## Operations
* [Accounts.md](Accounts.md): the seeded team account per role and the password policy.
* [Testing.md](Testing.md): test layers, how to run them, and the archived QA reports in [testing/](testing/).
* [Production_Checklist.md](Production_Checklist.md): what must be done before the public launch.
* [Support_Workflow.md](Support_Workflow.md): ticket lifecycle and standard operating procedures.

## Business and legal
* [Financial_Model.md](Financial_Model.md): revenue streams, payouts and wallet economics.
* [Partner_SLA.md](Partner_SLA.md): partner obligations and settlement terms.
* [Legal_Policies.md](Legal_Policies.md): terms of service and privacy policy drafts.

## Reports
* [Coworking_Pass_Final_Report_EN.docx](Coworking_Pass_Final_Report_EN.docx): the submitted project report. It is a
  snapshot and is not regenerated from these files.
