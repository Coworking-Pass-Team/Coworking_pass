# Local typefaces

The presentation includes the Latin subset of each font. Arabic text uses the browser's system Arabic fallback. Each family has a separate SIL Open Font License in this folder.

| Local file | Distribution source |
| --- | --- |
| inter-tight.woff2 | [Fontsource Inter Tight 5.2.5, variable upright](https://cdn.jsdelivr.net/npm/@fontsource-variable/inter-tight@5.2.5/files/inter-tight-latin-wght-normal.woff2) |
| instrument-serif-italic.woff2 | [Fontsource Instrument Serif 5.2.5, regular italic](https://cdn.jsdelivr.net/npm/@fontsource/instrument-serif@5.2.5/files/instrument-serif-latin-400-italic.woff2) |
| jetbrains-mono.woff2 | [Fontsource JetBrains Mono 5.2.5, regular upright](https://cdn.jsdelivr.net/npm/@fontsource/jetbrains-mono@5.2.5/files/jetbrains-mono-latin-400-normal.woff2) |
